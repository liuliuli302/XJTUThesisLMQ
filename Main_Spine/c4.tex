\xchapter{基于大语言模型多智能体协同的视频摘要方法}{Multi-agent Large Language Model-based Video Summarization Method}

本章提出一种基于大语言模型多智能体协同的视频摘要方法。该方法通过 Planner Agent 的全局规划、多个 Expert Agent 的分工评估以及上下文记忆增强，对视频片段的重要性进行多维度协同建模，并将段级评分映射为帧级摘要结果。4.1 节给出问题分析与方法动机；4.2 节介绍方法整体流程与各模块设计；4.3 节通过对比实验与消融实验验证方法的有效性；4.4 节对本章工作进行总结。

\xsection{问题提出}{Problem Statement}

随着大语言模型在视频摘要任务中的应用不断深入，免训练方法已经能够借助文本理解与语义推理能力，对视频内容进行较高层面的重要性评估。然而，对于开放域长视频而言，如何在保持免训练方法迁移性强、实现简洁等优势的同时，从叙事结构、视觉亮点、情绪变化与信息增量等多个维度对片段重要性做出更准确的综合判断，仍是一个有待解决的问题。尤其在视频来源复杂、拍摄方式多样的开放域场景中，摘要系统不仅需要识别局部重要内容，还需要保证保留下来的片段能够共同服务于视频整体主题的表达。

从任务需求来看，这一问题可以进一步概括为评价维度划分、评分策略生成与时序上下文利用三个方面。在评价维度层面，视频摘要往往需要同时关注叙事推进、视觉显著性、情绪表达与信息增量等多种语义线索，因此有必要对不同维度的判断依据进行更清晰的区分和建模。在评估策略层面，不同类型视频对关键内容的定义并不相同，例如新闻视频更强调信息密度，叙事短片更依赖情节推进，生活记录则更关注情感表达，因此评分过程也需要能够根据视频主题和内容结构调整评价重点。在时序建模层面，长视频中的片段之间通常具有明显的上下文关联，若能在局部判断中适当引入历史语义信息，便有助于增强摘要结果的连贯性与整体性。从数据形式来看，开放域长视频通常具有内容跨度大、语义层次丰富和关键线索分布离散等特点：一方面，视频序列中既包含直接承担主题表达的核心片段，也包含用于铺垫情节、组织转场或渲染情绪的辅助片段，不同片段在摘要中的作用并不相同；另一方面，较长的时间跨度使片段重要性难以脱离其前后语境而被孤立判断。由此可见，视频摘要不仅需要识别局部具有较高保留价值的内容，还需要综合考虑片段对主题表达、叙事完整性与整体连贯性的贡献。

基于上述考虑，本章提出一种基于大语言模型多智能体协同的视频摘要方法。该方法由 Planner Agent 负责全局主题归纳与评分规划，由多个 Expert Agent 分别从叙事推进、视觉显著性、情绪表达和信息增量等维度提供独立证据，并通过记忆机制增强时序一致性，最终将段级结果映射为帧级摘要输出，从而形成一条面向开放域视频摘要的结构化推理流程。

\xsection{基于大语言模型多智能体协同的视频摘要方法}{Multi-Agent LLM Collaborative Video Summarization Method}

如图~\ref{fig:c4:method_overview} 所示，该方法对输入视频序列 $\mathcal{V}=\{f_{1},f_{2},\dots,f_{T}\}$ 的处理包含三个阶段：首先按照时间顺序将视频组织为片段集合 $\mathcal{S}=\{s_{1},s_{2},\dots,s_{N}\}$，并通过视觉语言模型生成对应的段级语义描述；随后由 Planner Agent 基于全部片段描述生成视频级规划结果，并结合多个 Expert Agent 的维度化判断得到段级重要性分数；最后通过上下文记忆增强评分一致性，并将段级分数映射为帧级表示，经背包优化生成满足长度约束的最终摘要结果。下面依次介绍各阶段的具体设计。

\xsubsection{视频结构化处理与段级描述生成}{Video Structuring and Segment-level Caption Generation}

在本章方法中，Planner Agent 与各 Expert Agent 均以文本提示为输入进行推理。若直接在帧级序列上操作，不仅会迅速消耗大语言模型的上下文长度，还会引入大量对摘要判断贡献有限的冗余视觉内容。为此，本模块在进入规划与评分之前，先将原始视频转化为长度可控、语义明确的段级文本序列，为后续各智能体提供统一的输入接口。如图~\ref{fig:c4:segment_caption_pipeline} 所示，这一转换包含时间结构化分段、片段内采样与段级描述生成三个步骤。

\subsubsection{时间结构化分段}
设输入视频为 $\mathcal{V}=\{f_{1},f_{2},\dots,f_{T}\}$，其中 $T$ 表示视频总帧数。本文首先按照时间顺序将视频划分为 $N$ 个连续片段，得到片段集合
\begin{equation}
  \mathcal{S}=\{s_{1},s_{2},\dots,s_{N}\},
\end{equation}
式中，$s_k$——第 $k$ 个片段，对应原视频中一段连续的帧区间；$N$——片段总数。具体实现中，本文按固定段数对视频帧序列进行均匀划分，各片段之间互不重叠。需要指出的是，上述分段以组织后续推理单元为目的，不要求精确对应视频的镜头或事件边界。

\subsubsection{片段内关键帧采样}
在获得片段集合后，本文并不对片段内全部帧逐一处理，而是从每个片段中按时间均匀选取少量代表性采样帧，以在有限输入预算下尽可能保留片段的主要动作变化与场景信息。设片段 $s_k$ 的采样帧数为 $m_k$，则其采样帧集合记为 $\mathcal{F}_k=\{f_{t_{k,1}},f_{t_{k,2}},\dots,f_{t_{k,m_k}}\}$，其中各采样位置在片段时间范围内均匀分布。当片段实际帧数小于预设采样数时，采样数截断至可用帧数。

\subsubsection{段级语义描述生成}
在完成采样后，系统将同一片段中的采样帧联合输入视觉语言模型，生成该片段对应的段级语义描述。设片段 $s_k$ 的采样帧图像集合为 $I_k$，则段级描述生成过程可表示为
\begin{equation}
  Cap_s(k)=\mathrm{VLM}_{\mathrm{seg}}\big(I_k;\theta_{\mathrm{VLM}},\pi_{\mathrm{seg}}\big),
\end{equation}
式中，$Cap_s(k)$——第 $k$ 个片段的段级描述；$\mathrm{VLM}_{\mathrm{seg}}(\cdot)$——面向片段描述生成的视觉语言模型；$I_k$——片段 $s_k$ 对应的采样帧图像集合；$\theta_{\mathrm{VLM}}$——视觉语言模型参数；$\pi_{\mathrm{seg}}$——段级提示模板。与逐帧独立描述不同，段级描述将同一片段内的多帧画面作为整体输入，要求模型围绕片段中的持续动作、主要事件与场景上下文输出单条紧凑文本。多帧联合输入使模型能够捕获片段内部的动作延续与时间演变，而单条输出约束则有效控制了描述冗长度，使后续提示拼接时各片段在长度与信息密度上保持可比。表~\ref{tab:c4:seg_caption_prompt} 展示了段级描述生成的提示词模板。

经上述处理，视频结构化模块的最终输出为一组按时间排列的段级语义序列
\begin{equation}
  \mathcal{C}=\{(s_{1},Cap_s(1)),(s_{2},Cap_s(2)),\dots,(s_{N},Cap_s(N))\},
\end{equation}
式中，$\mathcal{C}$——段级语义序列；$s_k$——第 $k$ 个片段；$Cap_s(k)$——与该片段对应的文本描述；$N$——片段总数。该序列保持了视频的时间顺序，并将原始帧流压缩为可直接输入大语言模型的段级文本表示。由此，后续 Planner Agent 与各 Expert Agent 无需再处理高维视觉序列，而能够围绕统一的文本语义接口开展全局规划与局部重要性判断。

\xsubsection{全局规划与多专家协同评分}{Global Planning and Multi-Expert Collaborative Scoring}

在获得段级语义序列 $\mathcal{C}$ 之后，下一步需要将文本描述转化为可比较的段级重要性分数。若由单一提示同时承担主题识别、全局概括和局部打分三种职责，模型往往难以在有限上下文中兼顾全局语境与片段细节。为此，本章方法将评分过程拆分为三个相互衔接的步骤：首先由 Planner Agent 基于全部片段描述建立视频级规划，随后由四类 Expert Agent 从各自维度对每个片段独立评分，最后由 Planner Agent 参考各 Expert 的评分结果与理由给出综合主分数，并通过显式加权生成最终段级得分。如图~\ref{fig:c4:planner_expert_scoring} 所示，这一拆分使全局语境建模、局部维度证据生成与综合研判各自在独立的提示空间中完成，避免了单一提示同时承担多种职责时的信息竞争。

\subsubsection{Planner Agent 全局规划}
Planner Agent 接收全部片段描述 $\{Cap_s(1),Cap_s(2),\dots,Cap_s(N)\}$ 作为输入，从整体视角推断视频主题、生成全局摘要并分配专家权重，其输出记为视频级规划结果
\begin{equation}
  \mathcal{G}=\{z,Cap_v,\mathbf{w},\mathcal{R}\},
\end{equation}
式中，$z$——从有限主题集合中选取的视频主题标签；$Cap_v$——视频级全局语义摘要；$\mathbf{w}=[w_s,w_v,w_e,w_i]$——四类 Expert 的动态权重向量；$\mathcal{R}$——Planner 给出的文本化规划依据。上述四个输出分别服务于后续评分的不同环节：$z$ 用于稳定后续提示中的任务语义，$Cap_v$ 为逐段评分提供跨片段语境，$\mathbf{w}$ 决定不同评分维度在最终融合时的相对贡献，$\mathcal{R}$ 则记录规划阶段的推理依据以便于结果回溯。为保证不同维度的分数可以在同一尺度下加权，权重经归一化后满足 $\sum_{m}w_m=1,\;w_m\ge0$；当模型未返回有效权重时，系统退化为均匀分配。表~\ref{tab:c4:planner_plan_prompt} 展示了 Planner 全局规划的提示词模板。

\subsubsection{多专家逐段评分}
在获得规划结果 $\mathcal{G}$ 之后，系统对每个片段执行逐段评分，流程分为专家评分与 Planner 综合评分两步。第一步，四个 Expert Agent 分别从叙事推进（Story）、视觉显著性（Visual）、情绪表达（Emotion）与信息增量（Information）四个维度，基于视频主题 $z$、全局摘要 $Cap_v$ 与当前片段描述 $Cap_s(k)$ 给出各自维度的分数与理由，各维度的具体角色提示见表~\ref{tab:c4:expert_prompt}。四类专家从各自维度独立评分，使最终结果不会被单一语义线索主导，同时各维度的判断依据以分数与文本理由的形式显式保留，便于后续 Planner 综合研判与结果回溯。第二步，Planner Agent 在接收到四类 Expert 的评分与理由后，将其与视频主题、全局摘要及当前片段描述一并作为输入，综合参考各维度证据给出主分数 $S_{\mathrm{plan}}(k)$。这一顺序设计使 Planner 的判断不再仅依赖自身对片段的单次理解，而是能够在多维度证据的基础上进行全局校准与综合研判。在具体实现中，各 Expert 评分与 Planner 逐段评分均采用统一的提示结构：系统提示声明智能体角色，用户提示注入视频主题、全局摘要、历史上下文与当前片段描述（Planner 的提示中额外包含各 Expert 返回的分数与理由），模型返回分数与评分理由。表~\ref{tab:c4:planner_seg_prompt} 展示了 Planner 逐段评分的提示词模板。

\subsubsection{分数融合}
Planner 与各 Expert 返回的原始分数均被归一化到 $[0,1]$ 区间。在此基础上，段级最终分数定义为 Planner 主分数与加权专家综合分数之和
\begin{equation}
  S_{\mathrm{final}}(k)=S_{\mathrm{plan}}(k)+\sum_{m \in \{s,v,e,i\}} w_m\, S_m(k),
\end{equation}
式中，$S_{\mathrm{final}}(k)$——第 $k$ 个片段的最终重要性分数；$S_{\mathrm{plan}}(k)$——Planner 在参考各 Expert 证据后给出的综合主分数；$w_m$——第 $m$ 类专家的权重；$S_m(k)$——对应专家分数。该定义中，Planner 主分数已融入了对各维度 Expert 证据的综合研判，因此承担全局主导项的角色；四类 Expert 分数则以加权形式提供额外的维度化补充，使最终结果在 Planner 综合判断的基础上进一步保留各维度的独立贡献。由于 $S_{\mathrm{plan}}(k)\in[0,1]$、各 $S_m(k)\in[0,1]$ 且专家权重和为 1，最终分数 $S_{\mathrm{final}}(k)\in[0,2]$，其保留了相对尺度信息，供后续帧级映射与标准化处理使用。

在该阶段的输出中，每个片段除 $S_{\mathrm{final}}(k)$ 外，还保留 Planner 主分数、四类 Expert 分数及其对应的文本理由，形成兼具数值结果与语义证据的结构化评分记录。



\xsubsection{上下文记忆增强与帧级摘要生成}{Context Memory Enhancement and Frame-level Summary Generation}

前两小节分别完成了段级语义描述的构造与段级重要性分数的生成。然而，最终摘要输出仍需解决两个衍接问题：其一，逐段评分过程中如何利用已处理片段的语义信息来增强局部判断的一致性；其二，段级分数如何转化为与公开数据集评测协议一致的帧级表示。本小节依次介绍轻量上下文记忆注入、帧级分数映射与对齐以及背包优化摘要构造三个步骤。

\subsubsection{上下文记忆注入}
在 4.2.2 小节所描述的逐段评分过程中，Planner Agent 与各 Expert Agent 默认仅接收当前片段的描述与全局规划结果。然而，长视频中相邻片段之间通常存在明显的语义关联。为此，本章方法引入一种基于历史描述拼接的轻量记忆机制。

该机制无需额外训练参数，其核心做法是将已评分片段的段级描述按时间顺序拼接为文本上下文，并在评分当前片段时一并注入提示。设最大历史窗口长度为 $h$，则评分片段 $s_k$ 时实际送入提示的上下文记忆为
\begin{equation}
  \mathcal{M}_k^{(h)}=\{Cap_s(\max(1,k{-}h)),\dots,Cap_s(k{-}1)\},
\end{equation}
式中，$\mathcal{M}_k^{(h)}$——片段 $s_k$ 可访问的历史描述集合；$Cap_s(\cdot)$——对应片段的段级描述；$h$——最大历史窗口长度。当 $k \le h$ 时，集合自动缩短至所有已有描述；当记忆机制关闭时，$\mathcal{M}_k^{(h)}$ 为空集。在具体实现中，系统将 $\mathcal{M}_k^{(h)}$ 中各条描述以 ``Previous segment $i$: $Cap_s(i)$'' 的格式线性拼接，并作为提示中的 Memory context 字段分别注入 Planner 与各 Expert 的评分提示（见表~\ref{tab:c4:planner_seg_prompt}）。因此，该机制建模的并非抽象的长程依赖，而是最近若干已处理片段对当前判断的局部约束。

\subsubsection{帧级分数映射与对齐}
在完成全部片段的评分后，系统获得段级分数序列 $[S_{\mathrm{final}}(1),S_{\mathrm{final}}(2),\dots,S_{\mathrm{final}}(N)]$。然而，公开数据集通常在预定义的采样帧位置上提供标注与评测元数据，因此需要将段级分数映射回帧轴。由于各片段之间互不重叠，每一帧恰好归属于一个片段，本文采用确定性的区间回填策略，将每个片段的最终分数直接赋值给其覆盖区间内的全部帧。设第 $t$ 帧所属的片段索引为 $k(t)$，则稠密帧分数定义为
\begin{equation}
  F(t)=S_{\mathrm{final}}\big(k(t)\big),
\end{equation}
式中，$F(t)$——第 $t$ 帧的稠密分数；$k(t)$——第 $t$ 帧所属片段的索引；$S_{\mathrm{final}}\big(k(t)\big)$——该片段的最终重要性分数。在获得全帧稠密分数后，系统依据数据集提供的采样位置集合提取对齐后的帧级分数，并执行区间归一化，最终输出帧级分数序列 $\mathrm{Score}_{\mathrm{frame}}$，作为后续摘要构造与评测的直接输入。

\subsubsection{背包优化与摘要构造}
在公开数据集评测协议下，仅有帧级分数仍不足以生成最终摘要，因为标准评测要求提供满足长度约束的二值摘要向量。为此，系统首先利用数据集提供的 change points 将帧序列划分为若干候选评测分段，随后在总长度预算内求解 0/1 背包优化问题。设第 $j$ 个候选分段的平均帧分数为 $u_j$、帧长度为 $l_j$，摘要长度预算为 $L$，则摘要选择问题形式化为
\begin{equation}
	\max_{\mathbf{x}} \sum_{j=1}^{J} x_j\, u_j \quad
	\text{s.t.} \quad \sum_{j=1}^{J} x_j\, l_j \le L, \quad x_j \in \{0,1\},
\end{equation}
式中，$x_j$——第 $j$ 个候选分段是否被选入摘要的二值决策变量；$u_j$——该分段内帧级分数的均值；$l_j$——该分段包含的帧数；$L$——由视频总帧数与摘要比例共同确定的长度预算；$J$——候选评测分段总数。求解采用动态规划实现，被选中分段内的全部帧标记为 1，其余帧标记为 0，由此得到与原始帧序列等长的二值摘要向量，即为本章方法的完整输出。

至此，图~\ref{fig:c4:method_overview} 所示的方法链路已完整闭合：4.2.1 将原始帧流压缩为段级文本语义接口，4.2.2 通过 Planner-Expert 协同机制完成段级重要性推理，4.2.3 经由上下文记忆增强、帧级映射与背包优化将段级结果对接至公开数据集评测协议。下一节将在此基础上展开实验分析。

\xsection{实验与分析}{Experiments and Analysis}

\xsubsection{实验细节}{Experimental Details}
\subsubsection{预处理与视频分段}
本文对输入视频采用基于固定段数的均匀划分方式，将全部帧序列组织为 $N$ 个连续且互不重叠的片段。实验中默认将每段视频划分为 8 个片段，并在每个片段内按时间均匀采样 8 帧用于段级描述生成。在后续实验中，若无特别说明，均采用默认的 8 段均匀划分设置。

\subsubsection{模型与推理配置}
段级多模态描述生成阶段采用 Qwen3-VL-8B-Instruct 作为视觉语言模型，将同一片段内的采样帧图像联合输入模型进行理解，最大生成长度限制为 96 个 token，以在保留多帧联合理解能力的同时控制描述冗长度。在 Planner Agent 与各 Expert Agent 的文本推理阶段，统一使用 DeepSeek-V3.2 作为底层大语言模型，所有智能体共享同一模型接口，通过角色化系统提示实现职责分离；温度参数设置为 0.2，以在推理稳定性与表达多样性之间取得平衡。系统默认启用上下文记忆机制，在逐段评分过程中将至多 8 个前序片段的段级描述作为文本上下文注入 Planner 与各 Expert 的评分提示，以增强时序一致性并抑制冗余内容被高估。

\subsubsection{摘要生成与评测协议}
在得到段级重要性分数后，系统首先通过 4.2.3 小节所述的区间回填策略将其映射回采样帧位置，并经区间归一化得到帧级分数序列。随后，系统利用数据集提供的 change points 形成候选评测分段，并通过 Google OR-Tools 提供的动态规划求解器求解 0/1 背包优化问题，在摘要总时长不超过原视频 15\% 的约束下选择最优片段集合，生成最终二值摘要向量。

在评测协议方面，SumMe 数据集报告 Max $F_1$-Score，TVSum 数据集报告 Avg $F_1$-Score，均与各数据集的主流评估协议保持一致。

\subsubsection{实验环境}
全部实验均在 Ubuntu 22.04 环境下完成，硬件配置为单张 NVIDIA RTX5090 GPU。除基于 Google OR-Tools 实现的摘要选择模块外，其余段级描述生成、帧级分数映射与评测流程均基于 PyTorch 实现。由于本章方法属于免训练推理框架，实验中不涉及额外参数训练或任务特定微调，全部结果均在统一硬件环境与一致推理配置下获得。

\xsubsection{对比实验}{Comparative Experiments}
为验证本文方法在公开视频摘要任务中的有效性，本节从 $F_1$ 分数定量分析、秩相关性系数定量分析与定性分析三个层面展开对比。前两者分别关注模型在标准数据集上的摘要选择性能与帧级排序一致性，后者则进一步考察所生成摘要在语义完整性、冗余抑制与叙事连贯性方面的主观质量。

\subsubsection{$F_1$ 分数定量分析}
表~\ref{tab:c4:vs_benchmark} 给出了本章方法与代表性监督方法、无监督方法及免训练方法在 SumMe 和 TVSum 数据集上的对比结果。为便于理解表中各基线方法的性能差异，下面对主要对比方法作简要介绍。

dppLSTM\cite{zhang2016video}：该方法将视频摘要建模为结构化预测问题，采用长短期记忆网络建模视频帧之间的变范围时序依赖关系，以此预测关键帧或关键子镜头，并结合辅助数据集与领域自适应策略缓解标注数据不足带来的训练困难。

ACGAN\cite{he2019unsupervised}：该方法构建了基于注意力条件生成对抗网络的视频摘要框架，由生成器预测帧级重要性分数并生成加权特征，由判别器判别加权特征与原始特征的差异，同时引入条件特征选择器和多头自注意力机制，以增强对长程时序依赖与关键时间区域的建模能力。

MPFN\cite{khan2024deep}：该方法提出了 ViT 辅助的深度金字塔细化网络，首先利用带有视觉 Transformer 主干的密集预测模块提取帧表示，再通过多尺度渐进式特征融合与定制金字塔细化块对多层特征进行逐级增强，最终预测帧级重要性分数并生成视频摘要。

CM-AVS\cite{huang2026conditional}：该方法从条件建模视角出发，引入多个具有语义含义的随机变量及其联合分布来刻画视频摘要中的关键因素，并通过辅助分布改进训练过程，同时设计条件注意力模块以缓解多模态输入带来的性能退化问题。

DR-DSN\cite{zhou2018deep}：该方法将视频摘要视为序列决策过程，利用深度摘要网络为每一帧预测被选中的概率，并基于强化学习进行端到端训练；其奖励函数同时约束摘要结果的多样性与代表性，因此无需人工标注即可完成无监督学习。

OM-AE\cite{rochan2019video}：该方法针对配对标注数据稀缺的问题，提出从非配对数据学习视频摘要的框架，通过对抗目标学习从原视频到摘要视频的映射，并额外引入多样性约束，使生成的摘要结果既符合目标摘要分布，又具备较好的视觉多样性。

SUM-SR\cite{li2024unsupervised}：该方法借鉴生成对抗学习思想但去除了判别器，采用更简单的损失函数，并通过重构器与帧选择器交替迭代训练的策略优化摘要生成过程；此外还在训练和测试阶段引入可训练掩码向量，以提升模型稳定性和训练效率。

SegSum\cite{bang2025integrate}：该方法显式利用 KTS 划分得到的片段信息，将视频片段级时空关系纳入摘要器的学习过程中，并结合集中注意力机制提升对片段内部与片段之间结构信息的建模能力，从而改善传统逐帧打分再汇聚策略的信息损失问题。

M3Sum\cite{wang2024m3sum}：该方法提出了一种模块化多模态免训练视频摘要框架，通过将音频、视频帧等不同模态统一转换为文本描述，并设计无参数的文本对齐机制进行跨模态融合，从而利用大语言模型的长上下文理解能力在无需训练数据和参数更新的条件下生成摘要结果。

\textbf{与免训练方法的比较。}\enspace 在同属免训练范式的方法中，本章方法在 SumMe 上分别高于 M3Sum-SP（43.6\%）和 M3Sum-PCoT（41.9\%）10.0 与 11.7 个百分点，优势显著。M3Sum 主要通过多模态文本化与无参数对齐机制完成摘要生成，而本章方法通过 Planner 全局规划与多 Expert 维度化评分将评价过程从单一语义判断拓展为多维度协同推理，因此在 SumMe 上取得了大幅度提升。与第三章提出的基于层级语义聚合的免训练方法（SumMe 48.1\%）相比，本章方法在 SumMe 上提升了 5.5 个百分点（53.6\% vs 48.1\%），表明多智能体协同推理在标注分歧较大的开放域视频上具有更强的鲁棒性与语义判别能力。在 TVSum 上，本章方法（55.6\%）低于第三章方法（61.1\%）5.5 个百分点，同时也略低于 M3Sum 的两个变体（56.9\%/57.6\%），关于这一差距的具体分析见下文。

\textbf{与无监督方法的比较。}\enspace 本章方法在完全免训练的条件下，于 SumMe 上（53.6\%）大幅超越早期无监督方法 DR-DSN（41.4\%）与 OM-AE（37.7\%），分别取得 12.2 与 15.9 个百分点的提升。上述结果表明，基于视觉重构或自编码器的传统无监督方法在语义建模能力上存在明显瓶颈，而本章方法通过引入多智能体协同推理机制，在不进行任何参数学习的前提下，能够更有效地捕捉视频语义结构与关键事件。与近年较强的无监督基线 SUM-SR（51.3\%）和 SegSum（54.0\%）相比，本章方法在 SumMe 上与 SegSum 仅差 0.4 个百分点，并高于 SUM-SR 2.3 个百分点，已达到可比甚至更优的水平，而这两种方法均需在目标数据集上执行完整的训练流程。

\textbf{与监督方法的比较。}\enspace 本章方法在 SumMe 上超越了全部监督基线：高于 dppLSTM（38.6\%）15.0 个百分点，高于 ACGAN（47.2\%）6.4 个百分点，高于 MPFN（51.9\%）1.7 个百分点，高于近年最优监督方法 CM-AVS（52.4\%）1.2 个百分点。需要指出的是，上述监督方法均依赖于人工标注的帧级或片段级训练信号，并通过端到端参数优化学习帧间时序建模与选择策略，而本章方法不引入任何可学习参数。在这一严格约束下仍能在 SumMe 上全面超越监督方法，充分印证了多智能体协同推理应用于视频摘要任务的有效性与发展潜力。

\subsubsection{秩相关性系数定量分析}

为进一步评价模型输出帧级重要性分数与人工标注之间的排序一致性，表~\ref{tab:c4:rank_correlation} 给出了本章方法与代表性视频摘要方法在 SumMe 和 TVSum 数据集上的 Spearman 系数 $\rho$ 与 Kendall 系数 $\tau$ 对比结果。由于秩相关性实验采用了更多面向帧级排序建模的对比方法，除前述 $F_1$ 对比中已介绍的 dppLSTM 外，还包括以下方法。

VASNet\cite{fajtl2018summarizing}：该方法提出基于软自注意力机制的监督式关键镜头摘要框架，以全连接网络替代双向循环网络完成序列到序列映射，从而在降低模型复杂度的同时建模帧间全局依赖关系。

DSNet\cite{zhu2020dsnet}：该方法提出 Detect-to-Summarize 框架，其中锚框式变体 DSNet-AB 通过多尺度时间兴趣提议实现关键片段定位与评分，锚点自由变体 DSNet-AF 则直接预测帧级重要性与片段位置，以显式引入时间一致性与摘要完整性约束。

DMASum\cite{wang2020query}：该方法围绕 Softmax Bottleneck 问题构建双混合注意力模型，通过二次自查询注意力增强模型表达能力，并结合单帧元学习策略提升小规模数据条件下的泛化性能。

PGL-SUM\cite{apostolidis2021combining}：该方法联合使用全局与局部多头注意力机制，并引入绝对位置编码，以从不同粒度上建模长程帧间依赖关系，从而提升视频帧重要性排序的时序感知能力。

MSVA\cite{ghauri2021supervised}：该方法融合静态视觉特征、运动特征等多种表示，并在特征融合前引入并行注意力机制，以增强对视觉内容与动态信息的联合建模能力。

iPTNet\cite{jiang2022joint}：该方法通过跨任务样本迁移，将视频时刻定位任务中的丰富标注知识迁移到视频摘要任务中，并利用重要性传播模块与协同教学机制改善帧级重要性估计。

CSTA\cite{son2024csta}：该方法将单视频帧特征堆叠为类图像表示，并采用二维卷积建模帧间与帧内关系，以较低计算开销提取时空显著性并预测帧级重要性分数。

LLMVS\cite{lee2025video}：该方法首先利用多模态大语言模型将视频帧转换为文本描述，再基于局部上下文由大语言模型评估帧重要性，并通过全局注意力机制对局部分数进行训练微调统一修正，以兼顾局部细节与整体叙事线索。

从表~\ref{tab:c4:rank_correlation} 的整体结果来看，本章方法在两个数据集上的秩相关性表现均处于领先水平。在 TVSum 上，本章方法取得了 $\rho=0.323$、$\tau=0.224$ 的最高 Spearman 与 Kendall 系数，分别超越此前最优的 LLMVS（$\rho=0.275$、$\tau=0.211$）0.048 与 0.013。在 SumMe 上，本章方法的 $\rho=0.282$ 与 LLMVS 并列最优，$\tau=0.214$ 略低于 LLMVS（0.253）与 CSTA（0.246）。上述结果表明，多智能体协同推理产生的帧级重要性分数在排序层面与人工标注具有较高的一致性。

\textbf{与传统监督方法的比较。}\enspace 相较于 dppLSTM、VASNet、DSNet 和 iPTNet 等主要依赖视觉表征回归或时序建模的监督方法，本章方法在 $\rho$ 与 $\tau$ 指标上均表现出显著优势。这表明仅依赖视觉显著性或局部时序依赖难以充分刻画帧级重要性与视频整体主题之间的对应关系，而本章方法通过 Planner 全局规划与多维度 Expert 协同评分，在段级推理层面对帧重要性形成了更全面的判断，进而在帧级映射后保持了较高的排序一致性。

\textbf{与近年强基线的比较。}\enspace 与 CSTA（SumMe $\rho=0.274$）和 LLMVS（SumMe $\rho=0.282$）等排序表现较强的方法相比，本章方法在 SumMe 上与 LLMVS 持平，在 TVSum 上则以 0.323 大幅超越 LLMVS（0.275）与 CSTA（0.255）。值得注意的是，LLMVS 虽然也利用大语言模型进行文本化评分，但仍需全局注意力机制进行训练微调，而本章方法在完全免训练条件下即取得了可比甚至更优的排序表现，尤其在 TVSum 上的优势说明多智能体协同推理在主题结构明确的视频上能够产生更接近人工排序的帧级分数。

\xsection{本章小结}{Chapter Summary}

本章围绕开放域长视频在免训练摘要场景下面临的全局理解不足、单一评分器适应性有限以及段级结果难以直接对接标准评测协议等问题，提出了一种面向视频摘要的多智能体大语言模型方法。与第三章基于层级语义聚合与相关性匹配的技术路线不同，本章以当前工程主链路为基础，将视频摘要过程组织为视频分段与段级描述生成、Planner 全局规划、多专家协同评分、记忆增强时序建模以及帧级映射与标准评测五个相互衔接的处理环节，从而把原始视频压缩问题转化为可解释的段级协同推理问题。

具体而言，本文首先利用分段机制将长视频重组为若干推理单元，并借助视觉语言模型生成段级多模态描述；在此基础上，由 Planner Agent 从全局范围内推断视频主题、生成全局摘要并动态分配专家权重，再由 Story、Visual、Emotion 与 Information 四类 Expert Agent 对各片段的重要性给出维度化判断，Planner Agent 进而参考各 Expert 的评分结果综合给出主分数；随后，系统通过轻量记忆机制将前序片段语义注入后续评分过程，并将段级最终分数映射到原始采样帧序列，结合归一化与 knapsack 摘要构造流程生成满足公开数据集协议的最终摘要结果。由此，第四章形成了一个从多模态描述、智能体协同推理到帧级评测输出的完整闭环。

在实验验证方面，本章方法能够在 SumMe 与 TVSum 两个标准数据集上形成稳定的公开基准表现，分别取得了 $53.6\%$ 与 $55.6\%$ 的 Mean $F_1$。进一步的设置级消融说明，分段粒度会对不同数据集产生不同影响：SumMe 更受益于相对较粗的分段，而 TVSum 更受益于更细粒度的片段建模。结合代表性案例分析还可以看到，当前方法能够在教程类视频中突出关键步骤，在景观类视频中抑制重复视角，并在 vlog 类视频中保留更具事件代表性的片段，从而体现出较好的跨类型适应能力与推理可解释性。

总体来看，本章从当前实际可运行的代码实现出发，完成了多智能体视频摘要框架的建模、实现路径抽象与实验分析，验证了以 Planner 为核心、以多专家协同推理为主体、以帧级映射和标准协议评测为落点的 training-free 视频摘要路线具有可行性。上述工作不仅为本文关于大语言模型驱动视频摘要的研究提供了第二条技术路径，也为下一章对全文工作的整体归纳与进一步讨论奠定了基础。
